= Audit Notary Web App
:toc: left
:toclevels: 2

The browser interface of Audit Notary: a Svelte 5 single-page application (SvelteKit, `adapter-static`), packaged as a
resource JAR that the application serves. Specification: `doc/specification/web-app.adoc`; reasoning:
`doc/concepts/web-app.adoc`. Structure and visuals follow `pm-web-app` of `pm-mcp-clients`.

== Layout

[cols="1,3"]
|===
|Path |Content

|`src/styles/`
|Design: `tokens.css` (the token contract of `pm-web-app`, pinned by commit in its header), `base.css`, `layers.ts`;
`tokens.test.ts` checks both themes for WCAG 2.1 AA

|`src/lib/brand/`
|Branding: name and descriptor keys, the mark (provisional, `doc/concepts/brand.adoc`), the wordmark, the mascot
(the notary bear, `mascot-notary.png`, a derivative of `doc/resources/brand/mascot-notary-source.png`)

|`src/lib/i18n/`
|Texts: the catalogue of `GET /api/v1/messages`, cached per application version; the ICU subset in `format.ts`

|`src/main/resources/META-INF/audit-notary/`
|Shared with the application and `web-mock`: the catalogue (`messages/messages_{en,de}.properties`) and the canonical
addresses (`canonical-addresses.json`)

|`src/lib/api/`
|The one `ApiClient`: same-origin `/api/v1`, anti-CSRF header, login on `401`, one shared event stream

|`src/lib/shell/`, `src/lib/templates/`, `src/lib/components/`
|The shell (rail, top bar, bottom bar, live indicator, command palette), the page templates and the closed vocabulary
of components

|`src/lib/views/`, `src/routes/`
|The views and the router; one catch-all route stub renders `AppRouter`
|===

== Commands

[source,bash]
----
npm run dev          # Vite dev server against web-mock (see the root README)
npm run test:ci      # Vitest
npm run lint         # ESLint, stylelint, the text-literal lint
npm run check        # svelte-check
npm run build        # build and check-build-output.mjs
----

Maven runs all of them (`frontend-maven-plugin`) and packages `build/` under `META-INF/resources`.

== Rules the Build Enforces

* No colour literal outside `tokens.css` (stylelint, `tokens.test.ts`).
* No literal text in markup and no raw controls in views (`scripts/text-literal-lint.mjs`); every text is a catalogue
  key, and both languages hold the same keys (`catalogue.test.ts`).
* No `style` attribute in markup: `style-src 'self'` (AUN-WEB-8) admits styles set through the CSSOM (`style:`)
  only.
* The build carries the policy `<meta>` with the bootstrap hash and loads nothing from another origin
  (`scripts/check-build-output.mjs`).
